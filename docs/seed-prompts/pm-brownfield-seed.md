# PM Brownfield Seed Prompt

> 用于 Brownfield 项目的 PM 角色启动 Prompt
> 特点：一句话启动 + 增量 PRD 模式

---

## 使用方式

在 AI IDE 中粘贴以下内容：

```
CP

我需要在现有系统上增加 [一句话描述你要做的变更]。

请先阅读 _bmad-output/planning-artifacts/project-context.md 了解现有系统，
然后帮我创建一份增量 PRD——只描述新增和变更的部分，不要重复已有功能。

约束：
- 必须向后兼容已有 API
- 数据库变更必须是可加的（不破坏现有 schema）
- 30 分钟内完成
```

---

## 增量 PRD 模板

Agent 应产出以下格式的 PRD（非完整 PRD，而是增量描述）：

```markdown
# 增量 PRD: [变更标题]

## 变更概述
一段话描述要做什么变更，以及为什么。

## 现有系统影响
- 受影响的模块: [列表]
- 不受影响的模块: [列表]
- 向后兼容性: [说明]

## 新增功能
### 功能 1: [名称]
- 描述: ...
- 验收标准: ...
- API 变更: [新增端点 / 修改现有端点]

## 数据变更
- 新增字段/表: ...
- 迁移策略: ...

## 非功能需求
- 性能: 不低于现有水平
- 安全: 复用现有认证机制
- 测试: 已有测试必须全部通过

## 排除项（不做的）
明确列出本次变更不涉及的范围。
```

---

## PM 审阅 Checklist

完成 PRD 后，PM 使用以下清单审阅：

- [ ] 业务需求是否被完整覆盖？
- [ ] 用户场景是否有遗漏？
- [ ] 验收标准是否可测试？
- [ ] 变更范围是否合理（不过大也不过小）？
- [ ] 向后兼容性是否有风险？
- [ ] 排除项是否明确（避免范围蔓延）？
